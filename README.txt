CARA MENJALANKAN (XAMPP / Laragon)
1. Copy folder "sim_mahasiswa" ke htdocs (XAMPP) atau www (Laragon).
2. Nyalakan Apache & MySQL.
3. Buka phpMyAdmin -> tab SQL -> paste isi database.sql -> Go.
4. Cek config.php (user/password MySQL) kalau beda.
5. Buka http://localhost/sim_mahasiswa/login.php
